# Security

These templates process business data (invoices, bank statements, client records). If you find a security issue in any workflow — an auth check that can be sidestepped, a data-handling flaw, an unsafe default — please report it privately.

**Contact:** dawid@kuliberda.ai

Please do not open a public issue for security reports. You will get a response within a few days, and a fix or advisory before the report is discussed publicly.
